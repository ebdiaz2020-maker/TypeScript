# Mini-proyecto 02 — Migrar JSX → TSX (Kata 1)

## Setup

```bash
npm install
npm run dev        # ver la app en el navegador
npm run typecheck  # ver los errores de tipos (lo importante de la kata)
```

## Tu tarea

En `src/components/` hay 3 componentes en `.jsx`:

| Archivo | Dificultad | Qué practica |
|---|---|---|
| `Saludo.jsx` | 🟢 fácil | props simples + prop opcional con default |
| `ListaUsuarios.jsx` | 🟡 media | array de objetos + interface + evento |
| `Contador.jsx` | 🟡 media | useState (inferido) + handlers |

## Timebox

⏱️ **10 minutos por componente.** Cuando suena, se resuelve en vivo.

## Aprobado ✅

- [ ] Cada uno tiene su `interface`.
