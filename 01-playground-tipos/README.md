# Mini-proyecto 01 — Playground de tipos + Kata 3

No tiene React. Es solo TypeScript puro para entrenar el ojo.

## Setup

```bash
npm install
npm run play   # compilador en modo watch: muestra errores en vivo
```

## Archivos

| Archivo | Para qué |
|---|---|
| `src/playground.ts` | Sandbox de calentamiento. Tocá, rompé, mirá. **No se entrega.** |
| `src/romper.ts` | **Kata 3.** Provocás 5 errores, los documentás y los arreglás. |

## Kata 3 — Romper y leer

⏱️ **Timebox: 15 minutos.**

En `src/romper.ts` hay 5 ejercicios.

### Aprobado ✅

- [ ] Los 5 errores provocados y documentados.
- [ ] Mensaje real del compilador en cada uno.
- [ ] Explicación propia (no copiada de IA).
- [ ] Los 5 quedan arreglados.

> 🗣️ En el cierre se eligen 2 alumnos al azar para explicar un error sin notas.
