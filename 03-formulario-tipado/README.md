# Mini-proyecto 03 — Formulario tipado (Kata 2)

## Setup

```bash
npm install
npm run dev        # ver el formulario
npm run typecheck  # validar tipos (esto es lo que se corrige)
```

## Tu tarea

Completá los `TODO` en `src/App.tsx`. El formulario tiene 4 campos:
`nombre`, `email`, `edad`, `aceptaTerminos`.

## Timebox

⏱️ **25 minutos.**

## Aprobado ✅

- [ ] Estado = 1 objeto con su `interface`.
- [ ] 1 solo `handleChange` para todos los inputs.
- [ ] Checkbox usa `checked`, no `value`.
- [ ] `handleSubmit` hace `preventDefault` y loguea el objeto.
- [ ] `npm run typecheck` pasa sin errores ni `any`.
